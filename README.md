# Repositorio de prompts para desarrollo de software

Prompts reutilizables para **analizar, diseñar, aprender, implementar y revisar** sistemas con especial preferencia por C#/.NET, pero sin imponer un tipo de aplicación ni una arquitectura.

## Contenido

- `01-Analisis-y-Diseno/001-diseno-desarrollo-sistemas.prompt.md` - Prompt maestro genérico de desarrollo incremental.

## Cómo usar PROMPT-001

1. Abre el archivo `.prompt.md` con VS Code.
2. Copia el texto en ChatGPT o en una herramienta compatible con prompts Markdown.
3. Rellena los campos `[NOMBRE]`, `[PROBLEMA]`, `[LISTA]`, `[NIVEL]`, etc.
4. Selecciona `APRENDIZAJE`, `IMPLEMENTACIÓN` o `REVISIÓN`.
5. Trabaja por iteraciones y registra resultados reales.

## Versionado

Los cambios de contenido deben describirse en commits Git. No guardes claves, datos personales ni material confidencial.
